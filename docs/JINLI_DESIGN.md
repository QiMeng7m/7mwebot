# 《星盘》玩法设计

> 微信群里的一套玄学玩法：求签、观星、放生、转运、开光、点星、锦鲤池，以及八字、八卦、天圆地方与四象。
> 所有命理内容均为娱乐向，不构成任何现实建议。

---

## 1. 一句话玩法

> **每天求一签、观一次星、放生一条鱼，攒香火点亮二十八宿，成为群里的天选之子。**

玩家目标分三层：

1. **今天**：求签、观星、放生、转运、开光、投池；
2. **本周**：周运目标、四象阵营周战、锦鲤池开奖；
3. **长期**：点亮 28 宿、收集签谱/牌鉴/星骰/卦谱、升到锦鲤王。

## 3. 日常系统

### 3.1 求签

- `求签` / `抽签`，每天 1 次。
- 36 支签，分 6 个等级：上上签 2%、大吉 5%、中吉 18%、小吉 40%、末吉 25%、凶 10%。
- 每支签有固定「宜」：观星 / 放生 / 转运 / 聊天。
- 欧气 = 等级基础值 + 连签加成 + 段位加成 + 星象 + 幸运星座 + 星盘 + 星骰/合盘临时值，封顶 120。
- 首次抽到某支签收入「签谱」。
- 连签里程碑：3/7/15/30 天发气运。
- `解签`：本地解读，每天 1 次。

### 3.2 观星 / 星骰

- `观星`，每天 1 次，获得 30 香火 + 星象加成。
- 掷三颗骰：行星 + 星座 + 宫位；行星给一个小效果：

| 行星 | 效果 |
|---|---|
| 太阳 | 今日欧气 +5 |
| 月亮 | 下次放生 +1 气运 |
| 水星 | 下次开光保底 -1 抽 |
| 金星 | 下次锦鲤池权重 +5% |
| 火星 | 下次斗星胜利 +5 香火 |
| 木星 | 今日香火收益 +10% |
| 土星 | 下次点星香火 -5% |

- 星骰图鉴：7 行星 + 12 星座 + 12 宫位，共 31 条。
- 每日星象全群共享：满月、水星逆行、金星入宫、木星高照、土星回归、日食、流星雨、紫气东来。
- 每周幸运星座：该星座成员求签欧气 +5。

### 3.3 放生

- `放生`，每天 1 次。
- 消耗 30 香火，获得 3 气运；宜放生翻倍，星象/欧气/星盘可加。
- 香火不足时不扣费，直接提示。

### 3.4 转运

- `转运`，每天 1 次。
- 消耗 50 香火，重抽当天签与欧气；宜转运减半，水星逆行再 -20，最低 10。
- 免费转运符可免一次费用。

### 3.5 开光 / 塔罗

- `开光` / `抽符`，每天最多 3 次，首抽免费，之后 100 香火/次。
- 22 张大阿卡纳牌：
  - 香火/气运奖励；
  - 欧气/免费转运；
  - 香火收益、池权重、保底等限次符；
  - 传说牌「世界」。
- 30 抽保底传说牌；星盘白虎与符可降低保底。
- 每张牌首次抽到收入「牌鉴」；集齐 22 张气运 +150。

### 3.6 锦鲤池

- `投池 N`：每天 10~200 香火，可分多次投入。
- `锦鲤池`：查看今日池子、参与人数、自己的投入、开奖状态。
- 21:00 开奖：
  - 参与人数 < 2：全额退还；
  - 中奖者按 `sqrt(投入) × (1 + 欧气/200) × 星盘池权重` 加权抽取；
  - 中奖者得池子 80%，所有参与者返还 15%，剩余系统回收；
  - 中奖者额外 +5 气运。
- 后台线程每分钟检查一次，自动开奖并全群公告。

## 4. 长期系统

### 4.1 星盘 28 宿

| 四象 | 每颗星 | 7/7 套装 | 行为门槛 |
|---|---|---|---|
| 青龙 | 香火收益 +1% | 额外 +10% | 累计求签 3/7/15/25/40/60/90 |
| 白虎 | 开光保底 -1 抽 | 额外 -5，传说牌 +2% | 累计开光 3/8/15/25/40/60/85 |
| 朱雀 | 欧气 +1 | 额外 +5 | 累计转运 1/3/6/10/16/24/34 |
| 玄武 | 锦鲤池权重 +1% | 额外 +8%，放生 +2 气运 | 累计放生 1/3/6/10/16/24/34 |

- 每颗星需要同时满足：香火 80/150/250/400/600/850/1200、气运 5/15/30/55/90/140/200、对应行为次数。
- `点星 青龙|白虎|朱雀|玄武`。
- 本命四象第一颗星香火减半、效果翻倍；MBTI 同象星效果 +20%。
- 28/28 可 `觉醒 青龙|白虎|朱雀|玄武`，四选一永久加成。
- 28 宿之后开放外圈 60 星，每颗全属性 +0.2%。

### 4.2 四象阵营

- 星座元素分阵营：火→朱雀、土→白虎、风→青龙、水→玄武。
- 每周按「阵营新点亮星数 ÷ 活跃人数」计分，避免人多必胜。
- 领先阵营成员求签欧气 +5。
- `四象榜` / `阵营榜` 查看。

### 4.3 周运

- `周运`：每周生成 3 个目标（求签/观星/开光/放生/转运/投池/点星）。
- 完成三个目标后 `领取周运`，获得 100 香火 + 5 气运。

### 4.4 段位

| 段位 | 气运门槛 | 欧气加成 |
|---|---|---|
| 咸鱼 | 0 | +0 |
| 小虾 | 15 | +1 |
| 鲫鱼 | 50 | +2 |
| 鲤鱼 | 120 | +3 |
| 锦鲤 | 300 | +5 |
| 欧皇 | 700 | +8 |
| 天选之子 | 1500 | +12 |
| 锦鲤王 | 3000 | +20 |

## 5. 八字 / 八卦 / 天圆地方 / 四象

### 5.1 设置出生时间

- `设置八字 1995-08-15 08:30`
- `设置生辰 1995年8月15日 辰时`
- `设置出生 19950815`
- 不知道时辰时只写年月日：`设置八字 1995-08-15`。

解析规则：

- 支持 `1995-08-15`、`1995/8/15`、`1995年8月15日`、`19950815`；
- 支持 `08:30`、`8点`、`辰时` 等时辰写法；
- 只保存年月日与时，不保存原始文本。

### 5.2 命盘

`八字` / `命盘` 展示：

- **四柱**：年柱、月柱、日柱、时柱（无时辰则三柱）；
- **五行**：木火土金水计数，标出最旺元素；
- **生肖**；
- **四象**：由最旺元素映射（木→青龙、金→白虎、火→朱雀、水/土→玄武）；
- **本命宿**：28 宿之一；
- **生命数字**：1~9；
- **五维评分**：爱情、事业、学习、财富、人际五项基础分；
- **天圆地方**：洛书九宫盘，中宫放日主；
- **今日卦象**：本卦与变卦。

计算为娱乐向：不处理节气交接、不查真太阳时，只保证稳定与好玩。

### 5.3 五维评分

- `五维` / `分支评分`：查看爱情、事业、学习、财富、人际五项评分。
- 基础分由五行分布、日主、生肖、四象决定，同一个人稳定不变。
- 每项附 10 格条形图与一句建议。
- 同时展示今日波动：`↑` 表示高于基础分，`↓` 表示低于基础分。
- `批命` 的输出会附带「今日五维」与最旺/最弱两项。

### 5.4 批命

- `批命` / `算命`，每天 1 次。
- 组合：八字五行 + 日主 + 今日干支 + 本卦 + 四象。
- 输出：今日主题、相生/相克关系、一句行动建议、今日五维。
- 奖励：香火 +10、今日欧气 +3。

### 5.5 起卦 / 卦谱

- `起卦` / `摇卦`，每天 1 次。
- 由出生信息 + 当天日期 + 用户 ID 稳定生成上卦、下卦、动爻与变卦。
- 每卦首次起出收入「卦谱」，共 64 卦。
- 奖励：香火 +10、今日欧气 +2。
- `卦谱` 查看已收集卦象。

### 5.6 AI 与固定数据

- **固定数据**：四柱、五行、生肖、四象、本命宿、生命数字、卦象、五维分数、今日波动。保证同一个人同一天结果稳定。
- **AI 文案**：`批命` 与 `解签` 的解读优先调用 AI，只传入结构化信息，不传群聊记录，不修改任何数字。
- **降级**：AI 关闭、超时或无返回时，自动使用本地固定模板；功能不中断。
- **成本**：批命/解签均为每日 1 次，调用量很小。
- **约束**：提示词要求不预测具体事件、不制造焦虑、不提及群聊或其他人。

## 6. 身份与社交

### 6.1 星座 / MBTI / 本命宿

- `我是 天蝎座` / `设置生日 10-24`：设置本命星；
- `我是 INFP`：设置 MBTI，NT→白虎、NF→玄武、SJ→青龙、SP→朱雀；
- 星座/MBTI 30 天内只能改一次；
- MBTI 首次设置且星盘为空时，免费点亮对应四象第一颗星。

### 6.2 合盘 / 斗星

- `合盘 @某人`：按太阳星座、四象生克、MBTI 轴匹配度计算 0~100 契合度；每天首次与同一人合盘双方欧气 +1。
- `斗星 @某人`：随机抽一象比星数，多者赢 10 香火（星骰火星符可加），每天 3 次。
- `@` 目标解析兼容「群昵称」（`data/group_nicknames.json`）：群昵称可以与联系人昵称完全不同（如 `西湖-金金` → `降娄`），也可以包含空格。

### 6.3 群像 / CP榜

- `群像`：本群星座与 MBTI 分布。
- `CP榜`：已设置星座的成员之间契合度最高的 5 对，按「昵称 × 昵称 — 分数」展示；只设置 MBTI 的成员不参与配对。

### 6.4 榜单

- `气运榜` / `锦鲤榜`：列出本群所有互动过的成员，按累计气运排序，同分时按香火排序。
- 求签只发香火、不发气运，因此刚求过签的成员也会以「气运 0（咸鱼）」出现在榜上，不会显示「气运榜还是空的」。
- `四象榜` / `阵营榜`：按本周四象阵营的星数/人数排名。

### 6.5 分享

- `分享` / `签卡`：生成今日签的文本分享卡。

## 12. 边界与风险

- 全部命理内容仅供娱乐，不构成现实建议；
- 锦鲤池只用虚拟香火，单日投入上限 200；
- 星盘与八字计算刻意简化，不追求专业排盘精度；
- 所有随机结果使用可注入的 `random.Random`，便于测试复现。
