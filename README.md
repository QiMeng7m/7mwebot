## 它是什么

把 webot 加入你的微信群，它会：

- **总结聊天记录**：说一句「总结一下」，立刻告诉你在忙的时候群里聊了什么。
- **管理待办事项**：@机器人 说「记一下 周五聚餐」，全群共享的待办清单就多了一条。完成了就「搞定」它，不想看了就「删掉」。
- **回答你的问题**：@机器人 问任何问题，它会结合群聊上下文回答你。
- **偶尔自己冒泡**：群聊热闹的时候，它也会插话接梗，像个普通群友。

所有操作都在一个网页控制台里完成，双击 EXE 就能用。

## 能做什么

### 1. 群聊待办

@机器人 说句话就能新建一条待办，全群都能看到。每个群独立管理，互不影响。

**怎么用**

群里直接说（@机器人 也可以）：
- `记一下 周五聚餐` —— 添加一条待办
- `查看待办` —— 看看还有哪些没做
- `搞定 3` —— 把第 3 项标记完成
- `删掉 2` —— 把第 2 项放进回收站
- `恢复待办 1` —— 从回收站捞回来（仅群管理员）

打开控制台的「群聊待办」页面，可以：
- 开关这个功能、选择哪些群启用
- 修改触发词（比如把「记一下」改成「备忘」）
- 设置每个群最多存多少条、多久后自动清理
- 查看所有群的待办列表，搜索、筛选、操作

### 2. 聊天总结

忙了几个小时没看群？直接说一句「总结一下」，机器人把刚才的聊天整理好发给你：谁说了什么、讨论了什么话题。

**怎么用**

群里直接说 `总结一下` 就行。也可以说 `前面说了什么`、`发生了什么`、`summarize`。触发词可以在控制台自定义。

控制台里可以调整：总结往前看多久（默认 8 小时）、用哪些词触发。

### 3. 对话问答

@机器人 然后问问题，它会结合最近的群聊内容来回答，而不是凭空瞎猜。

**怎么用**

- `@机器人 DeepSeek 和 Claude 哪个好？`
- `@机器人 刚才他们说的那个餐厅地址是什么？`

### 4. 群友昵称

群里的人默认显示的是微信号（wxid 开头的一串），很难认。控制台的「群友昵称」页面列出了每个群的全部成员，你可以给每个人取一个容易认的名字。

**怎么用**

打开控制台 → 群友昵称 → 选择群聊 → 在对应的人旁边填上你想叫的名字。

也可以在群里直接发送命令（仅管理员）：`@机器人 改名 wxid_xxx = 张三`

### 5. 趣味抽签 / 解签

说「抽签」（或 @机器人 抽签），机器人随机抽一支运势签（大吉到凶），配一句吐槽；再发「解签」，AI 只根据这支签的签文帮你解读，不读取群聊记录，也不会混入其他人的发言。

**怎么用**

直接发 `抽签` 即可，不需要 @机器人。**每人每群每天限抽一签、限解一次**；抽完发 `解签`，AI 会只根据你当天抽到的那支签的签文来解读（不读取群聊记录），AI 失败时可以重试。签文内容、等级名称、emoji 可以在控制台的「功能开关 → 趣味抽签」里自定义，**各等级概率固定**（上上签 2% / 大吉 5% / 中吉 18% / 小吉 40% / 末吉 25% / 凶 10%），不可调整。

### 6. 主动发言

不用 @它，群聊热闹到一定程度时，机器人会自己插话。

**怎么用**

在控制台的「功能开关 → 主动发言」里打开。可以调整它在多热闹的群里才开口（安静时闭嘴，热闹时活跃）。

### 7. 欢迎新人

有人刚进群，机器人会自动发一条欢迎消息。

**怎么用**

在控制台的「功能开关 → 欢迎新人」里打开。可以写多条欢迎词模板，不同的群用不同的模板。

### 8. 飞书沉淀

把群聊里的讨论自动整理到飞书表格里，按摘要、待办、需求、日常记录分类存好。

**怎么用**

在控制台的「功能开关 → 飞书同步」里填入飞书应用的 App ID 和 App Secret，开启后群聊内容会自动同步。也可以手动在群里说 `同步到飞书` 立即沉淀。

### 9. 群活跃查询

在群里直接说 `活跃查询`，机器人统计最近 15 天这个群的发言 Top5、每人的最后发言时间和窗口内未发言成员。也可以说 `活跃查询 7` 或 `活跃查询7天` 指定天数（最多 90 天）。

**怎么用**

群里直接发 `活跃查询` 即可，不需要 @机器人，任何人可用。数据来自机器人已接收并入库的群消息。

### 10. 修炼值 / 装备 / 切磋

群里发言自动攒修炼值，累计修炼值决定总榜、等级和月度赛季，灵石可以买装备、买免战券，也可以和别人切磋抢灵石。

**常用指令**（都不需要 @机器人）

| 指令 | 作用 |
|---|---|
| `修炼值` | 自己的修炼卡（等级、名次、灵石、攻击/防御） |
| `我的信息` | 一行快照：修炼值、灵石、攻击/防御 |
| `查询 莫小贝` | 查某人的修炼值和攻防（查不到人时不回复） |
| `修炼榜` / `月榜` | 总榜 / 本月赛季榜 |
| `商店` / `购买 铁剑` / `我的装备` | 买装备，装备永久有效（武器/护甲/饰品/坐骑） |
| `武力值` / `战力榜` | 看自己的攻击、防御与战力拆解 / 全群战力排名 |
| `打坐` / `打坐 5` / `打坐5` | 打坐 10 分钟（可指定 1~60 分钟），获得修炼值与当前功法进度 |
| `功法` | 查看所有功法、已学层数、进度与效果 |
| `学习功法 吐纳诀` / `切换功法 吐纳诀` | 花费 500 灵石学习功法 / 选择打坐时积累进度的功法 |
| `突破功法` | 功法进度满后突破；失败进度减半，连续失败 5 次掉一层 |
| `切磋 @某人` | 发起切磋，或引用对方消息后发 `切磋` |
| `切磋战绩` / `战神榜` | 生涯胜负与段位（青铜~战神） / 全群生涯胜场排行 |
| `强化 木剑` / `精炼 木剑` | 花灵石强化已拥有装备，最高 +15（每级 +2 武力） |
| `出售 木剑` / `出售 碳素竿` | 按原价 50% 回收已拥有的装备或鱼竿 |
| `境界` / `突破` | 境界进度 / 累计修炼值达到门槛即可突破（不扣修炼值，每重 +10 武力） |
| `Boss` / `Boss状态` / `Boss榜` | 挑战本周群 Boss / 血量进度 / 本周伤害排行 |
| `成就` / `称号` / `佩戴称号 战神` | 成就进度 / 已解锁称号 / 切换显示称号 |
| `抽奖` / `奖池` / `抽奖记录` | 每日首抽免费，之后 100 灵石/次（每日 3 次），奖池含修炼值/灵石/装备/鱼竿/鱼饵/免战券 |
| `买免战券` | 花 20 分换 4 小时免受切磋 |
| `修炼规则` | 查看当前计分规则 |

**等级**：默认 Lv0 潜水员到 Lv12 永恒，3000 分之后还有宗师、传奇、王者、神话、超凡、永恒六个进阶段位。

**钓鱼**：除鱼竿、鱼饵和图鉴外，累计钓到的鱼条数还会提升钓鱼等级（Lv1 新手 ~ Lv7 渔神），额外增加稀有与价值加成；最稀有的“神话”鱼（蛟龙/鲲/九色神鱼）是终局收藏目标。

**终局系统**：
- **装备强化**：任意已拥有装备可花灵石强化到 +15，每级 +2 武力，费用随等级和装备价格递增。
- **装备回收**：所有商店装备和已拥有鱼竿都可以发 `出售 名称` 回收，返还原价的 50%；强化消耗不返还，默认竹竿不可出售。
- **境界突破**：累计修炼值达到门槛即可突破境界（凡人 → 炼气 → … → 渡劫），不扣修炼值、没有等级限制，每重永久 +10 武力。
- **群 Boss**：每周全群共同挑战一个 Boss，按战力造成伤害；每人最多存 3 次挑战，每 30 分钟恢复 1 次；击杀后奖励池按伤害占比分配灵石，`Boss榜` 记录本周伤害。
- **成就与称号**：15 个跨玩法成就（等级、装备、强化、切磋、钓鱼、图鉴、神话鱼、连签、Boss、境界），解锁即发灵石奖励，并可佩戴对应称号展示在修炼卡上。

**每日抽奖**：**每天首抽免费**，之后每抽一次消耗 **100 灵石**；每人每天最多 **3 次**（免费 1 次 + 最多 2 次付费）。奖池包含灵石、修炼值、全部商店装备、全部非默认鱼竿、全部鱼饵和免战券；同一类奖励价值越高概率越低（例如 20 灵石很常见，5000 灵石极稀有）。抽到已拥有的装备/鱼竿会自动折算成一半价格的灵石。`奖池` 查看分类概率，`抽奖记录` 看最近结果。

**计分**：每条消息 +1，长消息、图片语音视频、被引用回复都有额外加分；**每天发「签到」+10**（签到分不受单条封顶影响，普通聊天不再算签到）；普通聊天单条最多 5 分。默认**每日不限、每分钟不限、重复内容也计分**，如需限制可在 `.env` 设置 `POINTS_DAILY_CAP`、`POINTS_RATE_LIMIT_PER_MIN`、`POINTS_DEDUP_WINDOW`（0 = 不限/关闭）。

**切磋**：武力值高更容易赢，但胜率封顶 92%；武力差距越大，赢下后抢到的灵石越少。每天最多 10 次、被别人切磋 3 次、累计抢 50 灵石；输掉不扣灵石。

在控制台的「修炼值」页面可以看榜单、等级分布、商店和切磋流水；管理员可以分别调整成员的**修炼值**（只影响等级/榜单）和**灵石**（只影响消费余额）。

## 控制台一览

打开 EXE 后会自动弹出网页控制台，左侧菜单依次是：

- **运行状态**：看机器人在不在线、处理了多少消息
- **系统配置**：设置 AI 后端和 Key、机器人名字、数据目录、测试提示词
- **功能开关**：各项功能的开关和参数调整
- **群聊待办**：待办功能配置 + 所有群的待办列表
- **修炼值**：修炼榜、装备商店、切磋记录、等级分布与成员详情
- **群友昵称**：给群成员取别名
- **运行日志**：查看机器人运行记录

所有配置改完后点「保存配置」，重启机器人就生效。

## 安装

### Windows（推荐）

1. 从 [Releases](https://github.com/cancelGuMu/webot/releases) 下载 `webot-setup.exe`，双击安装
2. 或者下载 `webot.exe`，免安装直接双击运行
3. 首次打开会弹出配置向导，跟着走完就行

前提：电脑上已登录微信，想让机器人进的群需要先添加到通讯录（群聊右上角 `···` → 开启「添加到通讯录」）。

### macOS（实验）

macOS 通过 WeFlow 读取微信数据库，**不需要额外启动消息读取服务**。WeFlow 会把数据库密钥导出为 `all_keys.json`，webot 直接读取该文件。

```bash
git clone https://github.com/cancelGuMu/webot.git
cd webot
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements-macos.txt
cd ui && npm install && npm run build && cd ..

# 检查环境与 WeFlow 数据库
python tools/macos/weflow_setup.py diagnose
# 需要时提取 / 导入密钥（生成 all_keys.json）
python tools/macos/weflow_setup.py extract-keys
python tools/macos/weflow_setup.py import-keys
# 权限受限时可尝试重启钩子方式
python tools/macos/weflow_setup.py extract-keys-restart-hook

python desktop_mac.py
```

在 `.env` 中选择微信后端：

```bash
WECHAT_BACKEND=mac_ui       # UI 自动化，兼容性更好
# WECHAT_BACKEND=mac_hybrid # WCDB 直读，速度更快，依赖 all_keys.json
```

需要在系统设置中给终端授权「辅助功能」权限。

### 从源码运行（Windows）

```bash
git clone https://github.com/cancelGuMu/webot.git
cd webot
pip install -r requirements.txt
cd ui && npm install && npm run build && cd ..
python desktop.py
```

> **必须先准备原生 DLL**：仓库不包含 `native/windows/*.dll`（见 `.gitignore`），
> 缺了会报 `wx_key.dll not found` 或 `wcdb_api.dll not found`。
>
> 从 [Releases](https://github.com/cancelGuMu/webot/releases) 下载免安装版 `webot.exe`，然后解出所需 DLL：
>
> ```bash
> pip install pyinstaller
> python tools/extract_native_dlls.py --archive path/to/webot.exe --dest native/windows
> ```
>
> 也可以直接安装 `webot-setup.exe`，把安装目录下的 `native\windows\` 整个复制到本项目的 `native/` 下。

## 配置

所有设置都在控制台里直接改，不需要手动编辑文件。保存后重启机器人即可生效。

必须填的只有一项：在「系统配置 → AI 后端配置」里填入 API Key（DeepSeek 或 Claude 二选一）。

## 常见问题

**需要装什么？**
下载 EXE 双击就行，什么都不用装。

**会被封号吗？**
目前没有已知案例，但请自行评估风险。

**支持哪些 AI？费用多少？**
DeepSeek（推荐，极低价格）和 Claude。普通群一天用下来不到一毛钱。

**微信能最小化吗？**
读消息不受影响，发消息时微信窗口需要可见。

**支持多群吗？**
支持，默认监控所有群，也可以指定。
